# E-Commerce Sales & Profit Executive Dashboard (Tableau)

## 📌 Overview
This project presents an executive-level interactive dashboard built in Tableau to evaluate global e-commerce sales performance, profitability trends, and regional distribution[cite: 2, 3, 4, 5].

## 📊 Key Highlights & Metrics
- **Net Sales:** \$177M[cite: 2, 3]
- **Total Profit:** \$76M[cite: 2, 3]
- **Profit Margin:** 43.0%[cite: 2, 3]
- **Q4 Seasonal Peak:** Sales reached a maximum of \$23,319,594 due to holiday season discounts[cite: 3].
- **Global Distribution:** Highlighted top-performing regions like the US (\$102.2M) and India (\$7.7M)[cite: 4].
- **Regional Breakdown:** South region led profitability with \$23M[cite: 5].
